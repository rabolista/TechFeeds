# Tech and Feeds

Live technology headlines from Hacker News, optimized for quick reading —
built with Flutter for iOS and Android.

See [APP_OVERVIEW.md](APP_OVERVIEW.md) for what the app does and how it's
built, and [PRIVACY_POLICY.md](PRIVACY_POLICY.md) for the privacy policy.

## Getting started

```bash
flutter pub get
flutter run
```

## Regenerating the app icon

```bash
python3 tool/generate_icon.py
dart run flutter_launcher_icons
```
